## 🕒 React Props, Hooks & Reusable Components Project

This is a beginner-friendly React project that demonstrates **core React concepts** like state, props, hooks, reusable components, list rendering, and styling.

---

## 📌 Project Overview

This project includes:
- Rendering lists using `map()`
- Creating reusable components
- Passing data using props
- Managing state with `useState`
- Handling side effects with `useEffect`
- Creating a digital clock with live time
- Dynamic styling using props
