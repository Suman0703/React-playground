# React Notes – User Component (Props)

## 1. Introduction
This document contains beginner-friendly notes for understanding a simple React component that uses props to display user data.

---

## 2. What Is a React Component?
- A component is a reusable piece of UI
- Components are written as JavaScript functions
- Each component returns JSX
- Component names must start with a capital letter

Example:
```jsx
function User() {
  return <h1>Hello</h1>;
}
```
